# 06: 集中 KSA 语义并简化上游接入

**What to build:** 后续开发者可以在明确的 KSA 模块内理解和修改模型识别、summary 预算及缓存约束，标准 vLLM 接入保持小而清晰，现有使用行为不变。

**Blocked by:** 05 — 移除独立页分配器与旧缓存接口。

**Status:** ready-for-agent

- [ ] 按 KSA locality、减少上游侵入、减少代码量的优先级整理现有语义，合并重复模型识别、summary 预算计算和配置解释。
- [ ] 明确保留接口的参数、配置、不变量、调用顺序、错误行为和性能约束，不以函数或行数减少替代模块契约改进，不新增仅转发调用的浅模块。
- [ ] 只为真实变化设置接口边界，不扩展其他模型、summary 策略或分布式能力；需要迁移共享接口时先保留兼容形式，完成调用迁移后再删除旧形式。
- [ ] 保留 `ksa_cudagraph` 配置键及其与 `enforce_eager=True` 共存的局部 decode graph 语义，不纳入标准 compilation/cudagraph 配置改造。
- [ ] 保持现有功能限制；BF16 作为已有验证范围，不宣称其他 dtype 已验证，也不擅自新增 dtype 禁用限制。
- [ ] 通过行为测试、相关静态检查和模型评估验证契约；覆盖标准 KSA 路径及普通 Qwen3 功能兼容，以原容差确认无新增回退并记录未执行项。
