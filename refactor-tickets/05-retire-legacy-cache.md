# 05: 移除独立页分配器与旧缓存接口

**What to build:** KSA 缓存统一依托标准 scheduler 页生命周期运行，验证者仍能观察缓存布局、可见性、取消释放与复用行为，无需独立页池或旧模型缓存构造接口。

**Blocked by:** 04 — 移除专用服务入口与独立 runner。

**Status:** ready-for-agent

- [ ] 盘点 `KSAPagePool`、模型 `new_cache()` 及相关旧接口的剩余调用，先迁移仍有价值的验证，再删除独立分配器和仅服务旧路径的接口。
- [ ] 保留生产 `KSAGPUModelRunner` 所需的 scheduler 页映射与缓存约束，不误删标准路径需要的能力。
- [ ] 通过有意义的接口验证页映射、layout、visibility、取消释放与后续请求缓存复用；测试围绕可观察行为，删除仅服务已移除实现的测试。
- [ ] 运行相关检查和模型评估，以原容差验证分块 prefill、多步 decode、批处理及 eager/graph 场景无新增回退。
- [ ] 检查保留的生产、验证和性能测量调用均不再依赖已删除接口；记录既有失败及环境不可执行项。
