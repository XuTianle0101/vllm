## 性能

固定 1K/4K prompt、128 输出 token、关闭 EOS，每组一次预热和五次正式重复。
表内延迟和吞吐为五次均值，峰值为最大值；标准差和范围见结构化摘要。
加载与 HF 导出不在计时路径。并发数字独立报告，不与 HF batch=1 构造加速比。

T03 默认分页归档的 1K/4K 稳态 TPOT 为 44.060/44.523 ms；本轮为
45.352/45.773 ms，单请求仍有调度开销。HF 归档分别为 29.800/29.720 ms，
因此不宣称整体加速或单请求优于 HF。4K 并发从 4 提升到 8 的吞吐收益有限，
逐请求 Python attention、历史 gather 和大窗口计算仍需后续优化。

性能实验固定预分配约 4.243 GiB 页池（T03 默认池的八倍），所有并发使用同一容量，
测量组无抢占。HTTP 实验使用默认约 543 MiB 池；两组吞吐不可直接混用。
请求完成后有效 KV 和页占用回收，预分配池继续保留。不同页池配置也限制了与 T03
进程峰值显存的直接归因比较。
